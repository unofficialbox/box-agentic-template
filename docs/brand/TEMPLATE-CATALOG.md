# Box Corporate Template catalog

This is a Markdown description of every slide in the Box Corporate Template (Q3 FY27). Use it to choose a layout and copy its structure; [BOX-BRAND.md](BOX-BRAND.md) has the rules and `config/brand.json` the exact values.

**Template facts:**

- **Canvas:** 16:9, 13.333 × 7.5 in.
- **Theme:** "Q2 FY27 Box", Inter Display fonts.
- **Slide layouts:** Content slide, Key statement, Blank, Blank left pattern, Blank right pattern, Product right pattern, the title slides, Draft only dividers, and Grid.
- **Title slide variants:** Box alone or with a partner, each on white, blue, or black.

The original `.potx` is not in this repository (72 MB, with licensed imagery). Ask the Box Brand team for the current file when you need native slide masters.
